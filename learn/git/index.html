What you will learn

  • Navigate with cd and ls
  • Init a repo and commit
  • Create and switch branches
  • Push and pull
  • Undo safely

How it works

Every lesson explains the idea in plain language, shows small runnable examples with their output, and ends with an exercise and a worked solution.
